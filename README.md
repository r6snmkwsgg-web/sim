# Washington Dynasty: Football GM league files

League files converted from Pocket GM 3. Load one in Football GM with New League, then "Enter league file URL".

- `WAS_Dynasty_FBGM_2081_Draft.json.gz`: the full league (every PGM free agent, all 6 PGM draft classes)
- `WAS_Dynasty_FBGM_2081_Draft_lite.json.gz`: the same league with the top 900 free agents and the next 3 draft classes, lighter for phones
- `WAS_Dynasty_extras.json`: storyline notes, franchise history events and staff-based budgets, read by the one-time console patch for leagues started from an older copy of these files

Both league files include team and player notes, franchise history in the Transactions and News pages, and coaching/health/scouting budgets set from the Pocket GM staff.
- `WAS_inseason_progs.user.js`: userscript (Tampermonkey, or the Userscripts app on iPhone) that turns on the 30% offseason / 70% in-season progression every time Football GM opens. It only acts in the WAS Dynasty league.
