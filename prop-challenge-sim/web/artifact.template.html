02

The rulebook beats the strategy

Same real data, same costs, same three strategies. Read the $300 limit as trailing behind your equity high-water mark, or as a fixed floor at $19,700. That one reading moves the pass rate by more than an order of magnitude.

StrategyDrawdown rulePass rate95% interval Drawdown failTimeoutEV / attempt

Intervals are a day-cluster bootstrap. Overlapping 24-hour windows are not independent samples, and a plain binomial interval computed as if they were comes out several times too narrow — in the flattering direction.

03

What the real data says

The ratchet, not the ratio

Under a trailing floor every zero-edge strategy lands near half a percent, and about 99% of failures are drawdown breaches rather than timeouts. The 5:1 gap between target and limit is not what stops you. Get $500 ahead and you have $300 of room from there, not $800.

Static is priced near fair

With a fixed floor, buy-and-hold lands right around 10% — straddling breakeven. That is not a strategy, it is the gambler's ruin bound of 300/1800 = 16.7%, less what the 24-hour clock and the costs take out.

Real and synthetic agree

Before this ran on HistData it ran on a driftless generator. The numbers barely moved — static buy-and-hold went 10.62% to 10.57%. The result is a property of the rules and the costs, not of any particular market.

04

Run it on your own data

The Python engine this is ported from carries 99 tests, needs no third-party packages to run them, and is validated end to end against gambler's ruin. The browser port is checked against the same invariants.

python run_tests.py                  # 99 tests, no installs
node web/verify.js                  # 26 checks on the browser port
python -m propsim mc --symbol EURUSD --source cache/bars/EURUSD_60s_histdata_2022-2023.csv \
                       --attempts 10000 --workers 8
Prices: HistData.com EURUSD M1, bid, via github.com/adampy/fx-ml. Spread modelled at 0.8 pip with rollover widening; $5 round-turn commission. HistData is bid-only, so the spread is modelled rather than measured.
